# Windows design

Native WinUI 3 controls, Segoe UI Variable, theme resources, Mica backdrop and system accent. Follow Microsoft NavigationView, command, typography and spacing guidance. Main destinations: Capture, Gallery, OCR, Export, Projects, Help. Use 4/8 px spacing, 24 px page padding, clear headings, visible labels and keyboard accessible controls. Scroll content at small window sizes. Keep lengthy options in expanders. Status includes text and progress rather than color alone. Honor the system theme and animation settings through native controls.

References: https://learn.microsoft.com/windows/apps/design/basics/ ; https://learn.microsoft.com/windows/apps/design/controls/navigationview ; https://learn.microsoft.com/windows/apps/design/style/spacing
